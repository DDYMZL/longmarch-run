# V2.0 管理后台测试报告（活动设置 / 积分排名 / 积分核对 / 组织调整 / 审计文案）

日期：2026-10-13 ｜ 范围：admin + backend（荣誉榜前 10 名）｜ 构建：`npm run build` ✓（vue-tsc 无类型错误，vite 产出 dist）

## 覆盖范围

- 新增菜单「活动设置」（`/activity`，code=`activity`，sort 11，默认仅超管可见，可在角色管理中授予）及视图 `views/ActivityView.vue`
- 「排名洞察」`pages/RankingsView.vue` 升级为积分口径：累计总积分指标、前 10 名荣誉榜（1~3 金银铜领奖台 + 4~10 荣誉卡）、明细表总积分列（步行/答题拆分）、人员档案积分 KPI 与来源标签、「积分核对」弹窗
- 「人员授权」`views/AccessView.vue` 新增「调整组织」弹窗（`PUT /api/admin/users/{id}/org`）
- 「审计日志」`views/AuditView.vue` 动作中文文案 + 下拉筛选（仍可输入自定义动作码）
- 后端 `admin_service.get_rank_overview`：podium 由前 3 名扩展为前 10 名（`rank_service.ELITE_SIZE`），不受筛选影响

## 环境

- 后端 `python run.py`（8010，openGauss 5118），admin `vite`（5173，代理 /api → 8010）
- 浏览器：内置 browser-use（视口 811×795，截图时 `body.zoom=0.62` 等效约 1300px 宽）
- 登录：密码登录获取超管 token 写入 localStorage
