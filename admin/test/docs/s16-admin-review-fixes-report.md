## 1. 修复与优化清单

| 编号 | 位置 | 问题 | 处理 |
| --- | --- | --- | --- |
| A1 | utils/liveUpdates.ts + 驾驶舱/大屏/排名 | 三个页面各自写 800ms 防抖定时器，大屏的定时器卸载时未清理 | 防抖收进 composable（dispose 时清理），页面只传 `onDataChanged`/`onActivity`；activity 统一转为 ActivityItem（负数自增 id 避免 key 冲突） |
| A2 | utils/format.ts（新） | formatTime/formatNumber 混在 WS 工具里；排名、组织、审计各自 `new Intl.DateTimeFormat`/`toLocaleString` | 统一时间与数字格式化，模块级复用 Intl 实例 |
| A3 | AuditView | 审计时间直接显示 UTC 串（比本地时间慢 8 小时） | 改为本地时间（含秒）；后端日期筛选把本地日期换算为 UTC 区间 |
| A4 | Quotes/Questions/Access/Orgs/Dashboard | 快速翻页、切换筛选时旧响应可能覆盖新结果 | 请求序号守卫，只采纳最后一次请求 |
| A5 | QuestionsView | 筛选/页大小变化先重置页码再加载，会发出两次请求；关键字每次输入都请求 | watch 驱动加载：筛选变化时重置页码，与翻页合并为一次请求；关键字 400ms 防抖；删除到越界页时回到末页 |
| A6 | QuotesView | 关键字只在当前页本地过滤，翻页后搜不到 | 后端 `GET /admin/quotes` 新增 `keyword`（内容/出处模糊匹配），前端防抖后走服务端搜索 |
| A7 | 后端搜索 | 关键字含 `%`/`_` 时 LIKE 当通配符，会匹配全部数据 | 寄语/题库/人员搜索用 `contains(..., autoescape=True)` 转义 |
| A8 | LoginView | 扫码状态用 setInterval 轮询，请求慢时会堆积；切换 Tab 后旧二维码的轮询结果仍可能写回 | 改为链式 setTimeout 加代次计数（2s 间隔），过期代次的结果直接丢弃 |
| A9 | api/request.ts | 401 时先清登录态再判断，"登录已过期"提示无法区分是否曾登录 | 先记录是否持有 token，再清理；silent 请求不弹提示 |
| A10 | router/menus.ts（新） | 菜单在侧边栏、路由守卫、角色勾选（MENU_CATALOG）三处重复维护 | 单一来源 `MENUS`，三处共用，删除 `MENU_ORDER`/`MENU_ITEMS`/`MENU_CATALOG` |
| A11 | AccessView | 角色启用/禁用后会用接口数据覆盖弹窗中未保存的勾选；组织筛选只显示末级名称，同名部门无法区分 | 本地更新开关状态，保留未保存勾选，切换中禁用开关；组织选项显示完整路径并支持搜索 |
| A12 | OrgsView | `default-expand-all` 在组织节点很多时会一次渲染整棵树 | ≤200 个节点时全部展开，超过时只展开顶层 |
| A13 | store/auth.ts | 登录时 username 被写入两次 | `setAuth` 改为 `setToken`，用户资料统一由 `setProfile` 写入 |
| A14 | QuestionsView | 模板下载与错误报告各写一遍 Blob 下载逻辑，CSV 转义也是重复实现 | 复用 `utils/download` 的 `saveFile`/`csvCell`（防公式注入） |

全部修复项功能不变且通过验证。数据量大时：列表统一走服务端分页和搜索；快速操作不会导致请求堆积或旧响应覆盖新结果；实时推送合并为防抖重载；组织树超过 200 个节点时只展开顶层。
