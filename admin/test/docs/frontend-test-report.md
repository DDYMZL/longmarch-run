### 前端问题

截图：`../images/questions-01-list.png`（列表全量）、`questions-02-filter-judge.png`（判断题筛选 5 条）、`questions-03-edit-dialog.png`（编辑回显）、`questions-04-create-500.png`（**新增 500 缺陷现场**：弹窗探针数据 + 红色错误 toast）。

**F1【低】 ElMessageBox 取消 / 接口失败时产生未处理 Promise 拒绝（4 处）**
- 位置：`QuestionsView.vue` `handleDelete`（await confirm 无 catch）、`handleSave`（无 catch）；`OrgsView.vue` `handleSave` / `handleDelete` / `handleSync` 同模式。
- 证据（控制台）：`msgid=7` `[warn] Unhandled error during execution of component event handler … at <QuestionsView>`（取消删除触发）；`msgid=11` 同类 at `<OrgsView>`（保存 500 触发）。
- 影响：用户无感知（axios 拦截器仍弹错误 toast、保存失败时弹窗保持打开），仅控制台噪音 + unhandled rejection；但会污染监控告警。
- 建议：`await ElMessageBox.confirm(...).catch(() => null)` 后判空返回；`handleSave` 增加 `catch`（或由全局 Promise 拒绝处理器统一兜底）。

**F2【低】接口错误提示不友好**
- 现象：失败 toast 直接展示 `Request failed with status code 500`。
- 建议：`admin/src/api/request.ts` 拦截器对 5xx 映射为「服务器繁忙，请稍后重试」等文案（4xx 可透传后端 `detail`）。

### 备注参看

## 5. 测试环境说明与证据效力

1. **截图覆盖**：三个页面共 13 张（见 `../images/`）：排名洞察 6 张、题库维护 4 张、组织架构 3 张。内置浏览器面板在部分交互期间处于隐藏状态（`visibilityState=hidden`），MCP 截图接口返回 `NATIVE_BROWSER_VIEWPORT_UNAVAILABLE`；题库/组织两页的截图改用无头 Chrome（puppeteer-core + 系统 Chrome，注入 `lm_admin_token` 后真实渲染）补采，成像为应用真实画面。控制台错误另存 `../images/console-errors.json`（含 2 条 500 资源错误 + 2 条 `pageerror: AxiosError`，为 F1 的独立证据）。
2. **自动化环境现象（非应用缺陷）**：面板隐藏时浏览器暂停 rAF，Vue 的 `dialog-fade` 等离场过渡冻结，导致对话框/消息在 DOM 中滞留（`display:block` 但已逻辑关闭）。整页刷新后即恢复。该现象仅在自动化隐藏窗口出现，正常浏览器不受影响。
3. **测试残留**：题目 id=16 已删、组织名称已回改、被删组织已通过同步恢复；探针用户 id=9（`=1+1`）保留作 CSV 防护证据。
