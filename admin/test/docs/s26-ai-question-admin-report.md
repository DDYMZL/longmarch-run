## 3. 验收中发现并修复的缺陷

**草稿预览渲染冻结**：生成完成后弹窗停留在「生成中」旧 DOM。根因是 `watch(items, revalidateAll, { deep: true })` 中 `revalidateAll` 每次给 `item.errors` 赋新数组，深度 watcher 被自身写回反复触发，递归更新超过 Vue 上限后中断整轮渲染 flush。
修复：`revalidateAll` 仅在错误签名变化时写回（`AiGenerateDialog.vue`）。修复后第 5、6、9 步全部正常渲染。

## 4. 结论

- Excel 导入链路（模板/上传/校验/确认/结果反馈）与 AI 链路互不影响，AI 失败不会阻塞题库其他功能；
- AI 草稿必须勾选确认后才会调用 batch-save 入库，待修正行不可勾选；
- 保存成功后列表自动刷新并显示成功/失败数量（失败行保留在草稿列表并给出原因）；
- 密钥不出现在任何前端代码与请求中（生成请求仅携带主题/数量等参数）。
