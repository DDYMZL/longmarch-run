## 备注

- P1I-03 的增量断言直接解析中文大数文本：`formatCn` 按千位取整，而增量 20000 为 1000 整数倍，两次取整偏移一致，解析差恒等于真实增量（非巧合，已论证）。
- 卡片不设 `wx:if` 组织门槛：全员目标是活动级数据，未选组织的用户（理论存在）同样可见，与组织同行/集体长征卡（`wx:if=orgName`）语义不同。
- 「距离下一阶段」文案的剩余步数同用 `formatCn`（4882.8万步），与需求示例的千分位写法（36,170,719步）是展示风格差异，大数下中文单位更可读。
