- 测试组织选用 11（华南-销售部，无历史数据污染）而非惯用的 12：组织 12 子树累计步数已超 65000（延安目标），卡片恒处「完成态」，无法验证中途态进度条与「当前到达 → 下一站」文案；组织累计步数只增不减，无污染组织时应选兄弟分支的未用组织。

- 节点 pct 的展示口径（已完成 ✓ / 当前占自身目标比例 / 其余 0%）由后端下发 status+pct，前端仅做标签合成，不含业务计算。
