# 星空长征会师章金色背景优化报告

- 日期：2026-10-27
- 类型：视觉优化（前端 Canvas 静态氛围层，无后端/SQL/admin 变更）
- 范围：吴起镇、延安所属会师章的地平线天光；节点状态、路线进度、命中交互均不变。

## 1. 现象与根因

会师章原有「地平线天光」使用纵向线性渐变，再通过 `fillRect` 铺到固定矩形区域。渐变只处理上下方向，左右边界在仍有金色透明度时被直接截断，因此吴起镇和延安附近出现明显的金色矩形背景，破坏星空连续性。

优化前证据：`frontend/test/images/epic-04-victory.png`，会师章特写可见光带两侧的矩形硬边。

## 2. 优化方案

修改 `frontend/utils/starMap.js` 的 `paintChapterScenery`：

- 将会师章矩形线性渐变改为椭圆径向渐变，中心暖金、外围完全透明，横向与纵向均自然消隐。
- 通过 `translate` + `scale` 控制天光位置和椭圆比例，保留原有金雾精灵叠加与低透明氛围，不增加逐帧绘制开销。
- 使用 `save` / `restore` 包围坐标变换，避免影响后续区段地景和暗角绘制。

该层仍在静态星幕离屏烘焙阶段绘制，路由数据、节点坐标、路线采样和帧内动画逻辑均未修改。`frontend/design.md` §4.6 已同步为「延安椭圆径向天光」。
