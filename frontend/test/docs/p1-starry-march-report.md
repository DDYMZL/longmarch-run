# P1-5 星空长征模式升级（小程序侧）测试报告

日期：2026-10-03 · 范围：长征页 Canvas 模式升级为独立体验模式「星空长征」（需求 §13）

## 改动摘要

纯前端改动（`pages/march/march.*`），无后端/API 变更：

- **模式更名**：插画地图 → 星空长征（按钮文案、注释、提示语）。
- **§13.2 视觉规则**：节点三态星形化 —— 已点亮=金色发光五角星（光晕呼吸+双层星）、当前=红色呼吸星（scale 呼吸 + 扩散脉冲环）、未解锁=暗色星点；路线=星河轨迹（发光金轨沿线新增 22 颗固定采样星尘，仅已完成段闪烁，相位/频率各异）。
- **§13.3 点亮动画**（`drawArriveFx` 重写，2.4s 四阶段）：亮起（亮度渐入）→ 扩大（星形 bump 至 1.9 倍回落）→ 粒子扩散（`makeArriveParticles` fx 创建时一次性预生成，抛物运动渐隐）→ 稳定发光（结束后回到常态呼吸，无跳变）。
- **§13.4 星空全景**：新增观景变换 `view {scale, ox, oy}`——单指拖动平移、双指捏合缩放（双指中心锚定、1~2.5 倍钳制、平移边界钳制使场景不离开画布）、双击复位；`draw()` 整体 save/translate/scale 包裹；节点命中改为触摸序列判定（干净单指轻点才触发，屏幕坐标逆变换到场景，命中半径随缩放保持屏幕恒定 22px），彻底区分拖动与点击。
- **性能（§13.4）**：静态背景离屏缓存（既有）、星点 82 颗/星尘 22 颗固定、粒子单节点 ≤14 总量 ≤64（离屏精灵不可用的低端设备减半）、仅当前节点持续动画，fx 预生成避免帧内分配。

## 备注

- 缩放为 1 倍时平移被钳制为 0（场景恰满画布，无可拖动空间），故验收顺序为先捏合后拖动——符合地图类交互惯例。
- 单指转双指时在 touchmove 里重新锚定捏合基准（dist0/scale0/中心点），避免缩放跳变。
- `bindtap` 已移除：拖动结束后的残余 tap 事件曾可能误触发节点跳转，触摸序列内自判定（未移动+短促才视为点击）从机制上消除该歧义。
